# TRACERS_data_routines
This is a repository containing functions that pull and plot data for ACE and ACI. There are also routines to obtain ephemeris and attitude data.

There's a Jupyter notebook that outlines the basic calling routines for ACI, ACE, and EAD files. For plotting the data, all specific keywords are documented in each plotting routine file (lib/ACE/ace_plotting.py, lib/ACI/aci_plotting.py).
